Python Assignment 1: Data Structures - Strings & Tuples

This repository contains the solutions for Python Fundamentals Assignment 1, focusing on core operations with Strings and Tuples in Python.

📋 Overview of Tasks


Joining text together—which is called concatenation—starts with the word 'Hello.' We then ask the user to enter their name, such as 'Sara,' and combine them to form 'Hello Sara.' After that, we attach ', welcome to Python programming' to the end, so the final output displays the complete sentence: 'Hello Sara, welcome to Python programming.

To pick out specific parts of the full welcome sentence, we used slicing and indexing to extract smaller pieces of text. First, we grabbed the very first and last letters—'H' and 'g'."

For changing and searching text, we used built-in string methods on the phrase 'Python beginner tutorial'. We converted all the letters to uppercase and lowercase, and then capitalized only the first letter to return the sentence to its original form. Finally, we counted how many times the letter 't' appeared and swapped out the word 'Python' with 'Machine Learning'.
